# モンスターハント ― アイコン射撃場

現れたモンスターを撃つ30秒の射撃場。HTMLプレイヤーのカートリッジで、画面コントローラー（十字キー＋A/B）の実験も兼ねる。

- 遊ぶ: https://oosawak.github.io/monster-hunt/
- 操作: タップで直接撃つ／十字キーで照準を動かしてAボタン（Space）で撃つ／Bボタン（KeyX）でスタート
- アイコンは RPG Awesome（アイコンフォント、SIL OFL 1.1）。フォントはプレイヤー側が供給し、本体には含めない
- 埋め込みURLも X の4,096文字に収まる
